
# n维仿射空间
>>>定义
设k是一个域,另$K^n={(a_1,a_2,...,a_n)|a_i\in K,i=1,2,...,n}$,则称$K^n$为数域k上的n维仿射空间,记为$K^n$.$K^n$上的每个元素称为一个点.
与此相应的,设$\gama 为仿射空间K中的任意子集,我们成为 \gama是一个*图形*$
在域k的多项式环$K[x_1,x_2,...,x_n]$中取定多项式$f(x_1,x_2,...,x_n)$定义
$$V(f)={(x_1,x_2,...,x_n)|f(x_1,x_2,...,x_n)=0,i=1,2,...,n}$$
称 其为k^n中的一个仿射代数曲线
