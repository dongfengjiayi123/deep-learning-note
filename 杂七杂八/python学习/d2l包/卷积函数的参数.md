```torch.nn.Conv2d</import> 
torch.nn.Conv2d(
    in_channels: int,          # 输入的通道数
    out_channels: int,         # 输出的通道数（卷积核的数量）
    kernel_size: Union[int, Tuple[int, int]],  # 卷积核大小
    stride: Union[int, Tuple[int, int]] = 1,   # 步长（滑动步幅）
    padding: Union[int, Tuple[int, int], str] = 0,  # 填充
    dilation: Union[int, Tuple[int, int]] = 1, # 膨胀率（空洞卷积）
    groups: int = 1,           # 分组卷积的组数
    bias: bool = True,         # 是否添加偏置项
    padding_mode: str = 'zeros' # 填充模式，默认零填充
)

```




```python

torch.nn.BatchNorm2d(
    num_features: int,          # 输入的通道数（核心参数）
    eps: float = 1e-05,         # 防止分母为0的极小值，默认1e-5
    momentum: float = 0.1,      # 滑动平均的动量，用于更新运行时的均值/方差
    affine: bool = True,        # 是否学习缩放（gamma）和偏移（beta）参数
    track_running_stats: bool = True  # 是否跟踪训练过程中的运行均值/方差
)

```


```python
torch.nn.AvgPool2d(
    kernel_size: Union[int, Tuple[int, int]],  # 池化窗口大小
    stride: Union[int, Tuple[int, int]] = None, # 滑动步长，默认等于kernel_size
    padding: Union[int, Tuple[int, int]] = 0,   # 边缘填充
    ceil_mode: bool = False,                   # 尺寸计算是否向上取整
    count_include_pad: bool = True             # 计算均值时是否包含填充的0
)
```


```python
torch.nn.Flatten(
    start_dim: int = 1,  # 从哪个维度开始展平（默认1，跳过批次维度0）
    end_dim: int = -1    # 展平到哪个维度（默认-1，展平到最后一个维度）
)
```
第0维度为通道数,第1维度为高，第2维度为宽
每个通道可以理解为提取不同的特征,不能全部变为一维向量
所以通道数要保留
