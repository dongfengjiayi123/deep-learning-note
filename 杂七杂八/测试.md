## 1. SPH 物理方法的基本原理

SPH 是一种**纯拉格朗日**流体离散方法：流体被离散为携带质量、速度、压强等物理量的粒子，粒子随流场运动，无需背景网格。任意场量 $A(x)$ 由邻域粒子插值得到：

$$A(x) = \sum_j m_j \frac{A_j}{\rho_j} W(x - x_j, h) \qquad (1)$$

$m_j$ 为粒子质量，$\rho_j$ 为密度，$h$ 为核函数支持半径，$W$ 为有限支撑的光滑核函数。由于粒子"携带"质量，式 (1) 天然满足质量守恒；动量方程 $\frac{dv}{dt}=-\frac{1}{\rho}\nabla P + g$ 中的梯度、散度、拉普拉斯算子均可化为对核函数的导数求和，把偏微分方程转化为粒子对相互作用的一组常微分方程，非常适合 GPU 大规模并行。

**核心思想**：用核函数加权求和替代场量微分运算，按时间步进求解粒子运动。

## 2. WCSPH 的核心物理思想

经典 SPH 用理想气体状态方程 $P=k_p\rho$，可压缩性高、密度波动大；严格不可压缩投影法又需每步求解 Poisson 方程、代价昂贵。WCSPH 采用 **Tait 状态方程**：

$$P = B\left[\left(\frac{\rho}{\rho_0}\right)^\gamma - 1\right], \quad \gamma = 7, \quad B = \frac{\rho_0 c_s^2}{\gamma} \qquad (7)(9)$$

取足够高的声速 $c_s$（保证马赫数 $M = v_f/c_s < \sqrt{\eta}$，$\eta\approx 0.01$），密度波动被限制在 1% 量级，即可在**不求解 Poisson 方程**的前提下近似不可压缩，同时保持每步计算量小、天然支持飞溅与破碎波等自由表面现象。

## 4. WCSPH 单步时间迭代的完整算法流程

初始化: 布置粒子(规则网格), 质量 m=ρ0·V, 位置 x, 速度 v=0  
循环每个时间步 Δt:  
┌──────────────────────────────────────────────────────────┐  
│ Step1 邻居搜索: 空间哈希网格(支持半径 h)重建邻域关系       │  
│ Step2 密度:      ρ_a = Σ_b m_b W(|x_a−x_b|,h)   (式4)    │  
│                 levelUp: ρ_a = max(ρ_a, ρ0)              │  
│ Step3 压强:      P_a = B[(ρ_a/ρ0)^γ − 1]       (式7)     │  
│ Step4 加速度:    压力: a_a += −Σ_b m_b(P_a/ρ_a²+P_b/ρ_b²)│  
│                         ·∇_a W_ab               (式6)    │  
│                 粘性: a_a += −Σ_b m_b Π_ab ∇_a W_ab (式10)│  
│ Step5 重力:      a_a += g                      (式3)      │  
│ Step6 积分:      v_a += a_a·Δt;  x_a += v_a·Δt           │  
│ Step7 边界:      边界粒子参与 Step2/4 相互作用防止穿透      │  
└──────────────────────────────────────────────────────────┘

Step 1 的空间哈希网格（`wp.HashGrid`）将邻居搜索从 $O(N^2)$ 降为 $O(N)$；Step 2–5 在 `kernel.py` 中实现为 GPU 核函数，由 `solverWcsph.py` 的 `stepWCSPH` 按上述顺序调度（密度与压力力对"流体-流体""流体-边界"对象对分别累加）。

## 6. 小结

WCSPH 以约 1% 的密度波动换取"免 Poisson 求解"的高效率，配合对称压力梯度、人工粘性与 CFL 时间步约束，可稳定模拟自由表面流体的飞溅、破碎波等效果，是本项目流体仿真的基础算法。
