# 📖 小说朗读器 —— 使用说明

一款可以**自由选择音色**朗读小说的桌面软件。基于微软 Edge 神经网络语音（edge-tts），免费、音质接近真人，支持 16+ 种中文音色（含方言/港台腔）。

## ✨ 功能

| 功能 | 说明 |
|---|---|
| 🎙️ 多音色 | 内置 16 种常用中文音色（晓晓、云希、云健、晓伊、台湾/香港/方言…），可一键刷新完整音色列表（600+ 种） |
| ▶️ 播放控制 | 播放 / 暂停 / 继续 / 停止 |
| ⏱️ 语速调节 | -50% ~ +50%，实时生效 |
| 🔊 音量调节 | 0 ~ 100%，实时生效 |
| 📄 小说解析 | 支持 .txt / .md，自动识别 UTF-8 / GBK 编码 |
| 🔖 进度记忆 | 自动记住上次读到的位置，下次打开同一文件续读 |
| 🎧 试听 | 选中音色后先试听效果再决定 |
| 📦 导出 MP3 | 一键把整本小说合成为分段 MP3 导出到文件夹 |

## 🚀 运行方法

### 1. 安装依赖（只需一次）

用 Anaconda 的 Python 打开命令行，执行：

```
E:\ProgramData\anaconda3\python.exe -m pip install edge-tts pygame chardet
```

### 2. 启动软件

```
E:\ProgramData\anaconda3\python.exe "f:\1\deep-learning-note\杂七杂八\8\3\小说朗读器.py"
```

> 也可以把上面这行存成 `启动.bat` 双击运行。

### 3. 使用

1. 点 **「打开小说…」** 选择你的 .txt 小说
2. 在 **音色** 下拉框选择喜欢的声音，点 **「试听」** 听效果
3. 点 **「▶ 开始朗读」** 即可
4. 播放中可随时调语速、音量，或暂停/继续/停止
5. 关掉软件再打开同一本小说，会自动续读

## 🔧 技术说明

- **语音合成**：`edge-tts`（调用微软 Edge 在线 TTS 服务，**需要联网**）
- **音频播放**：`pygame.mixer`
- **断句分块**：按句号/感叹/问号/逗号智能断句，每段 ≤250 字，长句自动二次拆分，无标点文本强制切分
- **双缓冲播放**：播放当前段的同时后台预生成下一段，段落间几乎无停顿
- **自动重试**：网络偶发连接重置时自动重试 4 次

## ⚠️ 注意事项

- **需要联网**：语音由微软在线服务实时合成，离线不可用
- 若刷新音色列表或朗读时提示网络失败，多为临时网络抖动，会自动重试
- 生成的小说片段临时文件会自动清理，不占空间
